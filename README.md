# ربات کدال به تلگرام

هر ۱۰ دقیقه اطلاعیه‌های تازه‌ی کدال را می‌گیرد، یک خبر کوتاه فارسی + یک کارت تصویری می‌سازد
و به یک کانال/چت تلگرام می‌فرستد. کاملاً رایگان و بدون نیاز به سرور یا کامپیوتر شخصی —
همه‌چیز روی **GitHub Actions** اجرا می‌شود.

---

## معماری، خلاصه

```
GitHub Actions (هر ۱۰ دقیقه، رایگان)
        │
        ▼
   search.codal.ir  → آخرین اطلاعیه‌ها (بدون فیلتر، طبق خواسته‌ی اولیه)
        │
        ▼
  فیلتر تکراری‌ها با state/seen.json  (TracingNo)
        │
        ▼
  (اختیاری) Gemini API  → بازنویسی عنوان خشکِ کدال به یک خبر کوتاه و روان فارسی
        │                  ⚠️ مدل مجاز به ساختن عدد/رقمی که در دادهٔ کدال نیست، نیست
        ▼
  Pillow + فونت وزیرمتن  → یک کارت خبری PNG (فارسی، راست‌به‌چپ)
        │
        ▼
      Telegram Bot API  → ارسال عکس + کپشن به کانال شما
        │
        ▼
  به‌روزرسانی state/seen.json و commit خودکار به همان ریپو
```

اگر ارسالِ یک اطلاعیه شکست بخورد (هر دلیلی)، در `state/seen.json` ثبت نمی‌شود و
اجرای بعدی دوباره امتحانش می‌کند — دقیقا همان قاعده‌ای که خودت قبلاً خواسته بودی.

---

## ⚠️ نکته‌ی مهم که باید قبل از هر چیز حلش کنی: دسترسی جغرافیایی کدال

خودت قبلاً به این نکته رسیده بودی: API کدال (`search.codal.ir`) گاهی از IPهای خارج از
ایران در دسترس نیست. من از همین‌جا (محیط Claude) نمی‌توانم مستقیماً `codal.ir` را تست کنم
تا با قطعیت بگویم سرورهای GitHub Actions (که روی دیتاسنترهای Azure در آمریکا/اروپا هستند)
می‌توانند به آن وصل شوند یا نه — این چیزی نیست که از روی دانش عمومی بشود مطمئن بود، باید
واقعاً تست شود.

**قدم اول واقعی، قبل از تنظیم زمان‌بندی خودکار:**

1. مخزن (repository) را طبق راهنمای زیر بساز.
2. یک‌بار به‌صورت دستی از تب **Actions** روی گزینه‌ی **Run workflow** بزن (این همان
   `workflow_dispatch` است که در فایل workflow گذاشته‌ام).
3. لاگ اجرا را نگاه کن:
   - اگر خط `X اطلاعیه دریافت شد` را دیدی → دسترسی برقرار است، برو سراغ تنظیم زمان‌بندی.
   - اگر خطای اتصال/timeout دیدی → یعنی همان مسدودیتی که پیش‌بینی کرده بودی واقعی است.

**اگر واقعاً مسدود بود، دو راهِ عملی (بدون درگیر کردن کامپیوتر خودت) وجود دارد
(و یک راهِ ظاهراً ساده که در واقع کمکی نمی‌کند):**

- **بهترین حالت:** یک سرویس رایگان یا خیلی ارزان داخل ایران (نه کامپیوتر خودت) که یک
  «آینه‌ی» ساده از همان JSON کدال را serve کند، و آدرسش را در متغیر `CODAL_API_BASE`
  بگذاری — کد بدون هیچ تغییری با آن کار می‌کند چون فقط همان مسیر URL را عوض می‌کند.
  گزینه‌های ابری ایرانی (مثل ابرآروان یا لیارا) این کار را می‌توانند انجام دهند، اما
  چون قیمت‌گذاری و سطح رایگانشان مدام تغییر می‌کند، حتماً قبل از هر تصمیمی خودت سایت
  فعلی‌شان را چک کن — نمی‌خواهم عددی که ممکن است دیگر درست نباشد بهت بدهم.
- یک ابزار عمومی reverse-proxy (مثل Cloudflare Workers) کمکی نمی‌کند، چون IP خروجی آن
  هم خارج از ایران است — همان مشکل GitHub Actions را دارد.
- اگر خودت یا یکی از آشناهایت از قبل یک سرور/میزبانیِ کوچک داخل ایران دارد (که ربطی به
  کامپیوتر شخصیِ خودت ندارد و همیشه روشن است)، کافی است روی آن یک اندپوینت ساده بسازی
  که همان JSON کدال را عیناً برگرداند؛ آدرسش را در `CODAL_API_BASE` بگذار.

من عمداً این تصمیم را برایت از پیش نگرفتم، چون بدون تست واقعی نمی‌شود گفت اصلاً لازم
است یا نه — شاید همان GitHub Actions ساده کار کند.

## قدم به قدم راه‌اندازی

### ۱) ساخت ربات تلگرام

1. در تلگرام با [@BotFather](https://t.me/BotFather) چت کن.
2. `/newbot` بزن، یک اسم و username انتخاب کن.
3. توکنی که می‌دهد (چیزی شبیه `123456789:AAxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`) را نگه دار.
4. یک کانال بساز (یا از یک کانال/گروه موجود استفاده کن) و ربات را به‌عنوان **ادمین** آن
   کانال اضافه کن (حداقل با اجازه‌ی ارسال پیام).
5. آیدی چت را پیدا کن:
   - اگر کانال عمومی است، همان `@channel_username` کافی است.
   - اگر خصوصی/عددی می‌خواهی، یک پیام در کانال بفرست و آدرس
     `https://api.telegram.org/bot<TOKEN>/getUpdates` را در مرورگر باز کن؛ عدد
     `chat.id` (معمولاً با `-100` شروع می‌شود) را بردار.

### ۲) (اختیاری ولی پیشنهادی) گرفتن کلید رایگان Gemini

برای بازنویسی خبر به لحن روان‌تر. اگر این مرحله را رد کنی، ربات به‌جایش یک خبر حداقلی
از روی عنوان رسمی کدال می‌سازد (بدون هیچ چیز ساختگی) — یعنی چیزی خراب نمی‌شود، فقط لحن
خشک‌تر است.

1. به [aistudio.google.com](https://aistudio.google.com) برو، یک API key رایگان بساز.
2. نام مدل فعلیِ رایگان را از [این صفحه](https://ai.google.dev/gemini-api/docs/models)
   چک کن (اسم مدل‌های Gemini مدام عوض می‌شود؛ من فعلاً `gemini-3.1-flash-lite` را
   به‌عنوان پیش‌فرض گذاشته‌ام، ولی اگر بعداً خطای «model not found» دیدی، کافی است مقدار
   Variable مربوطه را عوض کنی، نه کد را).

### ۳) ساخت مخزن روی GitHub

1. یک ریپازیتوری جدید بساز. **حتماً Public باشد** — چون فقط ریپوی عمومی، دقیقه‌ی اجرای
   نامحدود و رایگان برای GitHub Actions دارد (ریپوی خصوصی فقط ۲۰۰۰ دقیقه در ماه رایگان
   دارد که برای اجرای هر ۱۰ دقیقه کافی نیست). کد پابلیک‌شدن مشکلی ندارد، چون توکن‌ها را
   به‌صورت Secret جدا نگه می‌داریم؛ آن‌ها هیچ‌وقت در کد یا لاگ دیده نمی‌شوند.
2. همه‌ی فایل‌های این پوشه را در آن ریپو push کن.
3. برو به **Settings → Secrets and variables → Actions** و این‌ها را اضافه کن:
   - در تب **Secrets**: `TELEGRAM_BOT_TOKEN`، `TELEGRAM_CHAT_ID`، و در صورت داشتن،
     `GEMINI_API_KEY`.
   - در تب **Variables** (اختیاری، اگر بخواهی پیش‌فرض‌ها را عوض کنی):
     `GEMINI_MODEL`، `CODAL_API_BASE`، `MAX_ITEMS_PER_RUN`، `SEND_IMAGE`،
     `SYMBOLS_FILTER` (لیست نمادها با کاما جدا؛ خالی = همه‌ی نمادها، طبق خواسته‌ی اولیه).

### ۴) اولین اجرا — حالت Seed (خیلی مهم، این را رد نکن)

اگر همین اول زمان‌بندی خودکار را روشن کنی، ربات صدها اطلاعیه‌ی قدیمی موجود در پاسخ کدال
را «جدید» تشخیص می‌دهد و یک‌جا به کانالت می‌فرستد. برای جلوگیری از این سیل:

1. از تب **Actions**، وارد workflow به اسم **Codal to Telegram Bot** شو.
2. **Run workflow** بزن و مقدار `seed_only` را `true` بگذار.
3. این اجرا چیزی نمی‌فرستد، فقط همه‌ی اطلاعیه‌های فعلی را در `state/seen.json` علامت
   می‌زند تا از این به بعد فقط چیزهای واقعاً تازه ارسال شوند.
4. حالا زمان‌بندی خودکار (هر ۱۰ دقیقه) از خودش کار می‌کند، نیازی به کار دستی نیست.

## درباره‌ی تصویر

به‌جای اسکرین‌شات گرفتن از خود نامه‌ی کدال (که نیاز به مرورگر headless دارد و چون
`www.codal.ir` هم مشکل دسترسی دارد، نقطه‌ی شکست دیگری اضافه می‌کرد)، یک کارت خبری با
Pillow و فونت [وزیرمتن](https://github.com/rastikerdar/vazirmatn) (متن‌باز، لایسنس OFL)
می‌سازم: نام شرکت/نماد، متن خبر، و تاریخ/کد پیگیری. سبک‌تر، سریع‌تر، و به هیچ سرویس
بیرونی دیگری وابسته نیست.

اگر بعداً خواستی به‌جایش واقعاً بخشی از تصویر/PDF نامه را بگیری، بگو تا اضافه‌اش کنم —
فقط بدان که چون به `www.codal.ir` (نه فقط API جستجو) وابسته است، ریسک قطعی بیشتری دارد.

## محدودیت‌هایی که باید بدانی

- **حجم اطلاعیه‌ها:** چون فیلتر محتوایی نداری (طبق خواسته‌ی خودت)، در روزهای پرخبر
  (مثل اطلاعیه‌های میان‌دوره‌ای) ممکن است تعداد زیادی پیام در یک بازه‌ی ۱۰ دقیقه‌ای
  جمع شود. `MAX_ITEMS_PER_RUN` سقفی می‌گذارد و بقیه به اجرای بعدی موکول می‌شوند، ولی
  اگر بخواهی می‌توانی با `SYMBOLS_FILTER` فقط چند نماد خاص را فعال کنی.
- **سقف رایگان Gemini:** اگر در یک بازه‌ی کوتاه اطلاعیه‌ی زیادی بیاید، ممکن است به سقف
  رایگانِ روزانه/دقیقه‌ای Gemini بخوری؛ ربات در آن صورت خطا را لاگ می‌کند و خبر حداقلی
  (بدون هوش مصنوعی) می‌فرستد، چیزی از کار نمی‌افتد.
- **دقتِ زمان‌بندی GitHub:** کران هر ۱۰ دقیقه دقیق نیست؛ در ساعات شلوغ ممکن است چند
  دقیقه دیر اجرا شود. مشکلی ایجاد نمی‌کند چون تشخیص «جدید بودن» فقط بر اساس
  TracingNo است، نه بازه‌ی زمانی — هرچه بین دو اجرا اضافه شده باشد، در همان اجرای
  بعدی هم که کمی دیر برسد، ارسال می‌شود.
- **غیرفعال‌شدن زمان‌بندی بعد از ۶۰ روز بی‌فعالیتی ریپو:** این قانون خود گیت‌هاب است،
  ولی چون هر اجرا که چیزی جدید پیدا کند خودش `state/seen.json` را commit می‌کند،
  در عمل ریپو تقریباً هر روز فعالیت دارد و این مشکل پیش نمی‌آید.

## ساختار فایل‌ها

```
main.py                          منطق اصلی
requirements.txt                 وابستگی‌های پایتون
.env.example                     نمونه‌ی متغیرها (برای تست محلی، نه مقدار واقعی)
state/seen.json                  حافظه‌ی ضدتکرار (TracingNo)
fonts/Vazirmatn-*.ttf            فونت فارسی برای تصویر خبری
.github/workflows/codal-bot.yml  زمان‌بندی و اجرای خودکار
```

## تست محلی (اختیاری)

```bash
pip install -r requirements.txt
cp .env.example .env   # و مقادیر واقعی را داخلش بگذار
export $(grep -v '^#' .env | xargs)
python main.py
```
